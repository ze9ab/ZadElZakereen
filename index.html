1. مقدمة والتزام الخصوصية

مرحباً بكم في تطبيق «زاد الذاكرين» (Zad Al-Dhakireen) للورد اليومي والأذكار والمسبحة الإلكترونية الذكية. نحن نولي خصوصية المستخدمين وأمان بياناتهم أهمية قصوى، وتوضح وثيقة سياسة الخصوصية هذه أنواع البيانات التي يتعامل معها التطبيق وكيفية حمايتها واستخدامها بما يتوافق تماماً مع سياسات برنامج مطوري Google Play.

2. البيانات التي يجمعها التطبيق والغرض منها

  • بيانات الحساب والمصادقة (Google Sign-In & Firebase Authentication): عند اختيار تسجيل الدخول باستخدام حساب Google، يحصل التطبيق على المعرّف الفريد للحساب (UID)، الاسم الظاهر (Display Name)، وعنوان البريد الإلكتروني بهدف مزامنة تقدمك في الأوراد والتسبيحات عبر سحابة Firebase Cloud Firestore.
  • بيانات النشاط والأذكار المخصصة (Firebase Cloud Firestore & Local Room Database): يتم حفظ عدد التسبيحات، الأوراد المكتملة يومياً، والأذكار أو الأدعية المخصصة التي يضيفها المستخدم داخل قاعدة بيانات مشفرة ومعزولة لكل مستخدم بحيث لا يمكن لأي طرف آخر الوصول إليها.
  • الموقع الجغرافي الدقيق والتقريبي (Location Permissions — ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION): يطلب التطبيق إذن الموقع الجغرافي (اختيارياً وعند الطلب فقط) لغرض وحيد هو حساب مواقيت الصلوات الخمس فلكياً بدقة حسب إحداثيات منطقتك أو محافظتك. يتم حساب المواقيت محلياً داخل الجهاز، ولا يتم تتبع موقعك في الخلفية أو مشاركة إحداثياتك مع أي جهات إعلانية أو أطراف ثالثة.
  • إذن الإشعارات (Notifications — POST_NOTIFICATIONS): يُستخدم لعرض تذكيرات الأذكار المتجددة الدورية على شاشة الهاتف حسب الفترة الزمنية التي يحددها المستخدم، ويمكن إيقافها في أي وقت.

3. مشاركة البيانات مع الأطراف الثالثة

لا يقوم تطبيق «زاد الذاكرين» ببيع أو تأجير أو المتاجرة بأي بيانات شخصية للمستخدمين تحت أي ظرف. يعتمد التطبيق فقط على خدمات البنية التحتية الموثوقة من Google (Google Play Services وFirebase Authentication / Cloud Firestore) لتوفير خدمة تسجيل الدخول والمزامنة السحابية الآمنة.

4. أمن البيانات وحقوق المستخدم وحذف البيانات

  • تُنقل جميع البيانات المزامنة سحابياً عبر اتصال مشفر (HTTPS / TLS) وتخضع لقواعد أمان صارمة (Zero-Trust Security Rules) تضمن أن كل مستخدم يقرأ ويكتب بياناته الخاصة فقط.
  • يحق للمستخدم في أي وقت: تصفير سجل الإحصائيات، حذف أي ذكر مخصص قام بإضافته، تعديل ملفه الشخصي، أو تسجيل الخروج الكامل من الحساب عبر شاشة الملف الشخصي أو الإعدادات.

5. التواصل معنا

لأي استفسارات تتعلق بسياسة الخصوصية أو طلبات حذف البيانات، يمكنكم التواصل عبر البريد الإلكتروني الخاص بالمطور المسجل في صفحة التطبيق على متجر Google Play.

Privacy Policy — Zad Al-Dhakireen (زاد الذاكرين)

Effective Date: October 26, 2026 | Package Name: com.aistudio.zadaldhakireen.azkar

1. Overview

Zad Al-Dhakireen ("the App") is an Islamic daily Adhkar, Wird, and electronic Tasbih application. We are committed to protecting user privacy in full compliance with Google Play Developer Program Policies. We do not sell, rent, or share personal data with third-party advertisers.

2. Information We Access & How It Is Used

  • Authentication & Cloud Sync (Google Sign-In / Firebase Auth & Firestore): We use Google Sign-In via Android Credential Manager and Firebase Authentication to authenticate users and sync their personal Tasbih counts, daily Wird progress, and custom Adhkar in isolated per-user documents on Firebase Cloud Firestore.
  • Location Permission (ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION): Location access is requested solely to calculate accurate local Islamic Prayer Times (Fajr, Dhuhr, Asr, Maghrib, Isha) based on the user's geographic coordinates. Astronomical prayer time calculations run locally on the device. Location data is never tracked in the background or shared with third parties.
  • Notifications (POST_NOTIFICATIONS): Used only to display periodic rotating Dhikr reminders at user-configured intervals.

3. Data Security, Retention & Deletion

All cloud-synced data is encrypted in transit via HTTPS/TLS and protected by strict Firebase Firestore Security Rules (`request.auth.uid == userId`). Users can reset their statistics, delete custom Adhkar, or sign out at any time directly within the App.
